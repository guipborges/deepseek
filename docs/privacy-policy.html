Privacy Policy

Product: Ayvu Translator | Effective date: 2026-06-25

1. Overview

Ayvu Translator translates user-selected text through third-party language APIs, helps users save local flashcards, and opens pronunciation resources when requested. The extension is designed to keep user settings local and minimize data processing.

2. Data We Process

  • User-selected text from web pages for translation and pronunciation features.
  • User-provided settings, including API key and language preferences.
  • Flashcards saved by the user.

The extension does not collect health information, financial information, location, web browsing history, keystroke logs, mouse movement, or scroll activity.

3. Where Data Is Stored

  • Settings are stored locally in chrome.storage.local.
  • Flashcards are stored locally in browser IndexedDB.

This extension does not run its own backend server and does not store user data on developer-owned servers.

4. Third-Party Services

When translation, dictionary, or pronunciation features are requested by the user, selected text or searched words may be sent to or opened with:

  • https://api.deepseek.com/
  • https://api.dictionaryapi.dev/ (when applicable)
  • https://youglish.com/ (when the user opens YouGlish)
  • https://forvo.com/ (when the user opens Forvo)

Use of these services is subject to their own terms and privacy policies.

5. API Key Handling

The DeepSeek API key is stored locally in browser extension settings and is used only for requests initiated by the user.

6. Data Sharing

The extension does not sell user data. It does not transfer user data for purposes unrelated to the extension's single purpose. Data is transmitted only when needed to execute requested features. The extension does not use user data to determine creditworthiness or for lending purposes.

7. Security

Reasonable efforts are made to keep behavior limited to declared permissions. No client-side software can guarantee absolute security.

8. Children

This extension is not directed to children under 13.

9. Changes To This Policy

This policy may be updated from time to time. The effective date above will be updated when changes are made.
